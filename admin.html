Sobre este painel

Este painel foi construído em HTML, CSS e JavaScript, sem servidor. Ele é ideal para demonstrar e editar o site localmente. A autenticação é feita no navegador e não substitui uma proteção de servidor.

Para publicar com edição segura e agendamentos compartilhados entre dispositivos, será necessário conectar um back-end (por exemplo, Node.js, Supabase ou Firebase) e um banco de dados.
